
This readme introduce how to start scene_auto of each sensor:
take hy006_3814_0011 as an example:

1.1 hy006_3814_0011 linear mode:
./sample_scene param/sensor_hy006_3814_0011
init success
1.init param, set scene mode, resume
2.scene pause
3.set scene mode and resume
4.exit the sample
